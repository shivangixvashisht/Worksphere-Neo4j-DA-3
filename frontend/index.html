 Foreign keys become relationships

 Traversals of any depth

          
Chains of command, member networks and shortest paths use *1.. and shortestPath() instead of recursive CTEs.

        

        

          
 Safe console

          
Every query passes four layers: a keyword/procedure allowlist, an EXPLAIN type check, a READ transaction that Neo4j enforces, and a timeout with a row cap.
